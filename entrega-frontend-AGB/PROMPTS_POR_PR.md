## Cómo se construyó esta tabla

Cada fila viene de la sección correspondiente de [`prompts-AGB.md`](./prompts-AGB.md)
(ver también [`BRANCHES_LOG`](./BRANCHES_LOG) para el enlace directo
rama → sección). Donde el diario transcribe el prompt entre comillas, se
reproduce aquí igual; donde solo lo describe (`reusable-hooks-AGB`,
`adrs-AGB`, algunos hallazgos encontrados "de pasada"), se resume sin
inventar una cita que no existe en el propio diario.
